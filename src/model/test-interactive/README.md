# 演示交互模型 (Demo Mode)

本模块定义了系统的**演示交互模型与运行工具**。它为自动化测试（端到端测试 E2E 与业务需求测试 Requirement）提供人机交互可视化能力，将原本静默运行的无头脚本转化为面向真实人类观察者的结构化演示体验。

---

## 1. 核心定位与原则

- **测试独立性**：每个测试流程必须独立自洽，可单跑也可批跑；
- **开场即时感知**：测试启动首屏立即弹出居中开场总览，向观察者明确当前测试的目标与业务范畴；
- **零业务侵入**：演示模式仅在 `DEMO_MODE=true` 时激活。在非演示模式（CI/无头）下，所有延迟与弹窗自动跳过，保持高效纯黑盒执行；
- **显式粒度控制**：解决多流程复用准备动作（如登录、页面导航）时重复暂停的问题，由调用方使用自定义粒度表达意图，并明确决定是否显示步骤说明和操作动画。

---

## 2. 四阶段视觉与交互体系

演示模型为测试执行的生命周期建立了鲜明、协调的四重视觉语言：

| 阶段         | 核心 API                         | 呈现位置   | 主题色彩                                      | 徽章 / 标题                                          | 交互按钮             | 典型应用场景                                             |
| :----------- | :------------------------------- | :--------- | :-------------------------------------------- | :--------------------------------------------------- | :------------------- | :------------------------------------------------------- |
| **测试开场** | `演示_开场`<br/>`演示_说明_居中` | 屏幕中央   | **星空极光紫蓝**<br/>`rgba(30, 27, 75, 0.86)` | 标题 `🎯 测试演示目标`<br/>徽章 `演示开场` (Indigo)  | `开始演示 (Enter)`   | 每个用例启动的第一秒弹出，介绍测试名称、目标与验收点列表 |
| **步骤指引** | `演示_说明_右下角`               | 右下角浮窗 | **深海灰蓝**<br/>`rgba(15, 23, 42, 0.78)`     | 标题 `步骤指引`                                      | `继续演示 (Enter)`   | 核心业务执行过程中的每一步无遮挡操作提示                 |

## 3. 演示上下文控制机制

### 为什么需要演示粒度？

在真实测试中，往往存在逻辑复用。例如测试“表单提交”和“用户管理”时，都必须先执行“登录”与“标签切换”。  
如果每次复用登录都暂停展示“输入用户名、输入密码、点击登录”，演示过程会非常冗长。演示粒度允许调用方用自定义字符串表达一组操作在演示中的观察层级，并显式决定是否显示步骤说明和操作动画。

### 粒度不参与行为判断

粒度可以是任意业务字符串。框架不会分析粒度内容，也不会根据其中的关键词推断展示行为。所有行为都由独立字段明确控制：

```typescript
export type 演示上下文参数 = {
  /** 自定义演示粒度，只用于表达调用方意图 */
  粒度: string
  /** 是否跳过步骤说明弹窗；未指定时继承外层上下文 */
  跳过步骤说明?: boolean
  /** 是否跳过操作动画与等待；未指定时继承外层上下文 */
  跳过操作动画?: boolean
  /** 进入上下文前显示一次说明 */
  进入说明?: string
}
```

### 作用域执行（`演示_作用域`）

通过 `演示_作用域` 包裹代码，作用域内的 `演示_说明`、`演示_输入`、`演示_点击` 等操作会遵从显式配置。嵌套作用域未指定的控制字段会继承外层设置：

```typescript
// 只显示一次进入说明，随后快速完成内部输入、点击和切页
await 演示_作用域(
  {
    page,
    粒度: '表单现场准备',
    进入说明: '前置准备：自动登录系统并进入表单现场',
    跳过步骤说明: true,
    跳过操作动画: true,
  },
  async () => {
    await 登录演示页(page)
    await 切换演示标签(page, '表单组件')
  },
)

// 离开作用域后恢复外层设置
await 演示_说明_右下角(page, '未填写必填项时直接点击“验证并提交”...')
```

## 4. 在需求测试 (Requirement) 中的集成

需求模型执行器（`src/model/test-requirement/executor.ts`）天然知晓当前执行处于哪个阶段：

- `准备初始状态`
- `准备给定状态`
- `恢复快照`
- `流程步骤`

在 `demo.spec.ts` 中，通过步骤元信息无缝接入演示作用域：

```typescript
let 执行器 = 演示业务需求模型.创建执行器({
  系统上下文: { page: 参数.page, 新用户名后缀: 参数.新用户名后缀 },
  已满足依赖们: [演示需求依赖.浏览器],
  选择结果: 选择,
  执行命名步骤: async (名称, 执行, 元信息) => {
    let 是前置准备 = 元信息?.阶段 === '准备初始状态' || 元信息?.阶段 === '准备给定状态' || 元信息?.阶段 === '恢复快照'
    if (是前置准备) {
      // 前置准备步骤：不逐个显示说明和操作动画
      return await 演示_作用域(
        { 粒度: 元信息?.演示粒度 ?? '前置准备', 跳过步骤说明: true, 跳过操作动画: true },
        async () => await test.step(名称, 执行),
      )
    }
    // 流程步骤：显示当前步骤说明
    await 演示_说明_右下角(参数.page, 名称)
    return await test.step(名称, 执行)
  },
})
```

## 5. 公共 API 索引

- **生命周期卡片**：
  - `演示_开场(page, message, 标题?)`: 弹出居中极光紫测试演示目标开场卡片。
  - `演示_说明(page, message, 位置?, 标题?)`: 基础步骤说明卡片，支持居中或右下角。
  - `演示_说明_右下角(page, message)`: 右下角轻量步骤指引。
  - `演示_确认(page, message)`: 弹出居中琥珀暖金人工核验框，支持键盘 `Y` / `N` / `Enter` / `Esc` 快速决策。在非 Demo 模式下调用将直接抛错强制失败。
  - `演示_完成(page, message)`: 弹出居中翡翠墨绿成果定格卡片。
- **上下文控制**：
  - `演示_作用域(配置, 执行)`: 建立演示上下文作用域；粒度为自定义字符串，展示行为由独立字段控制。
  - `获得当前演示上下文()`: 读取当前活跃的上下文配置对象。
  - `获得当前演示粒度()`: 读取当前活跃的演示粒度。
- **页面交互高亮**：
  - `演示_点击(locator)`: 红色圆圈高亮并点击。
  - `演示_输入(locator, text)`: 蓝色圆圈高亮并录入文本。
  - `演示_勾选(locator)`: 橙色圆圈高亮并勾选。
  - `演示_选择(locator, option)`: 绿色圆圈高亮并下拉选择。
